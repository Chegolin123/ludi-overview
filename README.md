# Ludi — обзор

Фреймворк Telegram-ботов-персон: один бот = одна персона. Характер, доступы,
тарифы и память описаны в JSON, ядро общее.

Приватный репозиторий: `Chegolin123/ludi` — доступ по запросу.

## Задача

Персонаж в Telegram — это не только промпт. Это манера речи, реакции на
границы, память о разговоре, статы, мини-игры, напоминания и тарифы на
дополнительные функции. Если писать это в хендлерах, второй бот начинается
с копипаста.

## Идея

```
personas/<id>.json   — всё, что делает персонажа персонажем
bot_core.py          — общее ядро: БД, статы, память, тарифы, LLM
bot_handlers.py      — хендлеры, завязанные на текущую персону
run_bot.py           — выбор персоны и запуск
```

Новый бот — это копия JSON и новый токен. Код не меняется.

## Что описывается в персоне

- идентичность: имя, обращение, манера, приветствие;
- границы: что персона не обсуждает и как отказывает;
- доступы и тарифы: какие функции открыты бесплатно;
- память и статы: что хранится между сообщениями;
- владелец и разработчик — для эскалации.

## Качество

22 юнит-теста ядра: память, тарифы, границы, обработка ошибок LLM.
Данные в SQLite, логи читаются командами прямо из чата.

## Стек

Python · Telegram Bot API · SQLite · LLM API

## Что не публикуется

Реальные персоны, переписки, токены ботов, промпты и настройки тарифов.

## Почему код закрыт

Внутри — рабочие конфиги, ключи, персональные данные и коммерческая часть.
Публиковать это нельзя, поэтому открыт только обзор: что делает система,
какие решения внутри и чему она научила.
